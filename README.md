## 第 19 關：海大餐廳排隊系統

- [完整 C++ 主控台程式](level-19.cpp)：使用 `struct Customer` 與 `queue<Customer>`。

## 功能

1. 登記候位：輸入姓名與電話，自動取得候位編號並加入隊尾。
2. 叫下一位：顯示隊首客人並移出候位隊伍。
3. 看下一位：查看隊首，不移除候位資料。
4. 候位名單：依入隊順序列出編號、姓名與電話。
5. 查順位：依候位編號搜尋目前位置。
6. 打烊清空：清除候位單，下一輪編號重設為 1。

## 第 19 關資料結構重點

```cpp
struct Customer {
    int number;
    string name;
    string phone;
};

queue<Customer> waiting;
```

`push` 將客人加入隊尾，`front` 查看隊首，`pop` 移除隊首。這三種佇列操作為 $O(1)$；列出候位名單或查詢順位需逐筆檢查，為 $O(n)$。

## 第 20 關：二元搜尋樹種樹

- [完整 C++ 主控台程式](level-20.cpp)：包含插入、搜尋、刪除、四種走訪與樹高統計。
- 插入與搜尋依 BST 規則比較：較小往左，較大往右。
- 刪除涵蓋葉節點、單子節點和雙子節點；雙子節點以右子樹最小值（中序後繼）替換。
- 前序、中序、後序使用遞迴；層序使用 `queue<Node*>`。
- 平均操作時間為 $O(\log n)$，最壞退化成鏈時為 $O(n)$；樹的額外空間為 $O(n)$。

## 第 21 關：最大堆積排序

- 一次建堆（heapify）時間複雜度為 $O(n)$；逐一插入建立堆積為 $O(n \log n)$。
- Heapsort 的最佳、平均與最差時間複雜度皆為 $O(n \log n)$，原地排序額外空間為 $O(1)$。
- 網頁可逐步執行或自動播放，並觀察比較次數、交換次數、取出順序與排序結果。

## 第 22 關：雜湊表探險

- 雜湊函式為 `h(key) = ((key % 13) + 13) % 13`，表格容量為 13，索引範圍 0–12。
- 同時展示鏈結法與線性探測，支援插入、搜尋、刪除、自訂資料、逐步播放和碰撞統計。
- 線性探測刪除會留下墓碑，確保搜尋仍能穿過已刪除位置；負載因子為 α = n / 13。
- 鏈結法平均查找為 $O(1 + \alpha)$；低負載時線性探測期望為 $O(1)$，最壞搜尋為 $O(n)$。
